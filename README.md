# PalmaBlock — Functional Proof (Semana 3)

## Requisitos

- Navegador moderno (Chrome, Edge o Firefox).
- Opcional para servir local: Python 3 o Node.js 18+.

## Instalación

No requiere instalación ni dependencias. Solo clonar el repositorio:

```bash
git clone https://github.com/Bootcamp-BlockChain/ProyectoBlockChain.git
cd ProyectoBlockChain
```

## Cómo correrlo

Opción 1 — doble clic:

- Abrir `frontend/index.html` en el navegador.

Opción 2 — servidor local (recomendado):

```bash
cd frontend
python -m http.server 8080
```

Abrir `http://localhost:8080`.
